# MRI-based machine learning analysis of FCD type II

## Overview

This repository contains the analysis code and supporting files for the study:

**"Automated Detection of Focal Cortical Dysplasia in Epilepsy Using Machine Learning on Structural MRI"**

This proof-of-concept study evaluates the feasibility of using machine learning (ML) to distinguish patients with focal cortical dysplasia (FCD) type II-associated epilepsy from healthy controls (HCs) using structural MRI-derived neuroanatomical features.

The analyzed dataset comprised 167 participants after exclusion of three subjects because of severe motion artifacts and FreeSurfer reconstruction failure. Neuroanatomical features were extracted from T1-weighted structural MRI using FreeSurfer, with the Destrieux cortical parcellation atlas used for the primary analysis.

Two feature-reduction strategies were evaluated: Principal Component Analysis (PCA) and Elastic Net-based feature selection. Eleven supervised machine-learning classifiers were trained and evaluated within a stratified nested cross-validation framework comprising 10 outer folds and 5 inner folds.

The primary model-comparison metric was the area under the receiver operating characteristic curve (AUC). Among the evaluated classifier-feature reduction combinations, Random Forest with Elastic Net feature selection achieved the highest observed AUC.

Model interpretability for the best-performing pipeline was further investigated using SHapley Additive exPlanations (SHAP).

## Analysis workflow

The primary analysis workflow is implemented in the Jupyter notebook and consists of the following major stages.

1. Data preprocessing

The reconstructed neuroanatomical dataset is loaded and prepared for machine-learning analysis.

Variables not appropriate for model development are excluded, the diagnostic group is separated from the predictor set and used as the target variable, and the remaining MRI-derived features are prepared for subsequent processing.

The diagnostic target is coded as:

FCD type II-associated epilepsy = 1
Healthy control = 0

All preprocessing operations that could learn information from the data are incorporated into the cross-validation framework where appropriate to reduce information leakage.

2. Age residualization

Because age distribution differed between the FCD and healthy-control groups, age-related variation in MRI-derived features is addressed before model fitting.

Within the cross-validation framework, separate linear regression models are fitted to MRI-derived features using the reclassified age variable as the predictor. The age-predicted component is subtracted from the observed feature value, and the resulting residualized MRI features are used in subsequent model development.

Regression parameters are estimated using training data and subsequently applied to the corresponding held-out observations without refitting.

3. Feature reduction

Two alternative feature-reduction pipelines are evaluated.

PCA pipeline

The PCA-based pipeline includes:

removal of highly intercorrelated MRI features using a prespecified correlation threshold;
removal of features showing very weak univariate correlation with the target;
feature standardization using StandardScaler; and
Principal Component Analysis.

The candidate numbers of principal components evaluated during hyperparameter optimization are:

2, 5, 10, 15, 20, 30

The number of PCA components is selected within the inner cross-validation loop according to mean validation AUC.

Elastic Net pipeline

Elastic Net is evaluated as a supervised feature-selection alternative to PCA.

An Elastic Net-penalized logistic regression model using the saga solver is embedded within SelectFromModel.

The principal candidate values evaluated for Elastic Net feature selection include:

C:
0.01, 0.1, 1, 10

L1/L2 mixing ratio:
0.1, 0.5, 0.9

Feature-selection threshold:
1e-5, mean coefficient magnitude, median coefficient magnitude

Feature-selection parameters are optimized within the inner cross-validation procedure together with classifier hyperparameters.

4. Nested cross-validation

Model development and evaluation are performed using stratified nested cross-validation:

Outer cross-validation: 10 folds
Inner cross-validation: 5 folds

The outer loop is used to estimate model performance on held-out observations.

The inner loop is used for feature-processing decisions and hyperparameter optimization.

Preprocessing, age residualization, feature reduction, scaling, feature selection, and hyperparameter tuning are fitted using training data within the appropriate cross-validation level and are not fitted using the corresponding held-out test observations.

Outer-loop out-of-fold (OOF) predictions are pooled for final performance evaluation and model comparisons.

5. Classifier training

Eleven supervised machine-learning classifiers are evaluated:

Logistic Regression
Support Vector Machine (SVM)
Stochastic Gradient Descent (SGD) classifier
Gradient Boosting Classifier
LightGBM
Random Forest
K-Nearest Neighbors (KNN)
Gaussian Naive Bayes
Bernoulli Naive Bayes
Decision Tree
Multi-Layer Perceptron (MLP) neural network

Hyperparameters are optimized using grid search within the inner cross-validation folds.

For Bernoulli Naive Bayes, predictors are binarized immediately before classification using:

Binarizer(threshold=0)

Values greater than zero are encoded as 1, whereas values less than or equal to zero are encoded as 0.

The complete classifier hyperparameter search spaces are described in the associated manuscript.

6. Performance evaluation

Classifier performance is evaluated using pooled outer-loop OOF predictions.

The following performance metrics are calculated:

Area under the receiver operating characteristic curve (AUC)
Accuracy
Precision
Recall
F1-score

AUC is treated as the primary metric for comparison of classifiers and feature-reduction pipelines.

Ninety-five percent confidence intervals are estimated using bootstrap resampling.

Paired comparisons of model and feature-reduction performance are performed using outer-loop OOF predictions. Confidence intervals for differences in performance metrics are estimated using paired bootstrap resampling with 1,000 iterations.

Prespecified paired classification comparisons are additionally evaluated using McNemar's test.

ROC curves and confusion matrices for the selected model are generated from pooled outer-loop OOF predictions.

An exploratory subgroup analysis is also performed for MRI-negative/histopathology-positive FCD patients using their outer-loop OOF predictions.

7. SHAP analysis

Model interpretability for the best-performing Elastic Net–Random Forest pipeline is evaluated using SHapley Additive exPlanations (SHAP).

SHAP values are calculated for held-out outer-fold observations using models fitted without those observations. Feature-attribution results are subsequently aggregated across outer folds.

Mean absolute SHAP values are used to quantify the magnitude of feature importance.

Directional SHAP attribution is additionally evaluated to characterize the direction of feature contribution between FCD-associated epilepsy patients and healthy controls.

Bootstrap resampling with 1,000 iterations is used to estimate 95% confidence intervals for feature-importance and directional-attribution estimates.

The SHAP analyses are intended as exploratory model-interpretability analyses rather than confirmatory neuroanatomical inference.

## Reproducing the analysis

To reproduce the machine-learning analysis:

Step 1

Obtain the original MRI dataset from OpenNeuro dataset ds004199 if reproduction starting from the original imaging data is required.

Step 2

Perform the FreeSurfer reconstruction and neuroanatomical feature-extraction procedure described in the associated manuscript.

For reproduction of the machine-learning analysis from the tabular feature stage, place:

df_destx.csv

in the working directory expected by the notebook.

Step 3

Install the required Python dependencies:

pip install -r requirements.txt
Step 4

Open:

EpilepsyFullJourney(8-10-2026)(1).ipynb

using Jupyter Notebook, JupyterLab, or a compatible Google Colab environment.

Step 5

Run the notebook sequentially from the beginning.

The notebook should be executed in cell order because later analyses depend on objects and intermediate results generated by earlier preprocessing and model-development cells.

The principal computational order is:

Load reconstructed feature dataset
        ↓
Data cleaning and preprocessing
        ↓
Target and predictor definition
        ↓
Age handling/residualization
        ↓
Nested cross-validation setup
        ↓
PCA feature-reduction pipeline
        ↓
Elastic Net feature-selection pipeline
        ↓
Hyperparameter optimization
        ↓
Training of 11 classifiers
        ↓
Outer-fold OOF prediction generation
        ↓
Performance metric calculation
        ↓
PCA versus Elastic Net comparisons
        ↓
Selection/evaluation of the highest-performing pipeline
        ↓
Sensitivity analyses
        ↓
MRI-negative/histopathology-positive subgroup analysis
        ↓
SHAP model-interpretability analysis
        ↓
Generation/export of final tables and analysis outputs
Step 6

Compare the generated results with the performance tables and figures reported in the associated manuscript.

Because nested cross-validation, model fitting, and some machine-learning algorithms may involve stochastic operations, exact reproducibility depends on using the same software versions and random-state settings as the archived analysis environment.

## Statistical analyses

Statistical analyses were performed using a combination of Python and IBM SPSS Statistics.

The manuscript reports SPSS Statistics version 22 for conventional statistical analyses.

Statistical procedures used in the study include, where applicable:

Chi-square tests
Fisher's exact test
Phi coefficient
Cramer's V
Independent two-sample t-tests
Mann-Whitney U tests
McNemar's test
Bootstrap confidence intervals
Paired bootstrap comparisons of out-of-fold model predictions

A two-sided P value below 0.05 was considered statistically significant for the inferential analyses specified in the manuscript.

For machine-learning comparisons, AUC was considered the primary performance metric. Accuracy, precision, recall, and F1-score were treated as secondary performance metrics.

Model-performance confidence intervals and paired performance differences were estimated using bootstrap resampling with 1,000 iterations.

Where statistical-analysis files or SPSS syntax are included in this repository, they are provided to facilitate verification of the analyses reported in the manuscript.
